\section{Core Concepts: Singularity Functions and First-Order LTI Systems}
%--------------------------------------------------------------

\subsection{What Are Singularity Functions?}

\textbf{Singularity functions} are idealized mathematical inputs used to characterize the behavior of systems. In this lab, we focus on two:

\begin{itemize}
    \item \textbf{Heaviside Unit Step $u(t)$:} Represents an instantaneous switch from 0 to 1 at $t=0$. Mathematically, $u(t) = 0$ for $t < 0$ and $u(t) = 1$ for $t \ge 0$. In hardware, we approximate this by setting a digital pin HIGH and keeping it there.

    \item \textbf{Dirac Delta Impulse $\delta(t)$:} A very narrow, very tall spike with unit area. Formally, $\delta(t) = 0$ everywhere except $t=0$, and $\int_{-\infty}^{\infty} \delta(t) \, dt = 1$. In hardware, we approximate this with a short pulse of width $T_p \ll \tau$.
\end{itemize}

\noindent
The response of a linear time-invariant (LTI) system to these inputs is fundamental:
\begin{itemize}
    \item \textbf{Step response $s(t)$:} Output when $x(t) = V_s \cdot u(t)$ (a sudden voltage applied and held).
    \item \textbf{Impulse response $h(t)$:} Output when input is a narrow pulse that approximates $\delta(t)$.
\end{itemize}

\subsection{First-Order LTI Systems}

A first-order causal LTI system is fully described by the differential equation:
\begin{equation}
\tau \frac{dy(t)}{dt} + y(t) = K x(t),
\label{eq:firstorder}
\end{equation}
where:
\begin{itemize}
    \item $\tau$ is the \textbf{time constant} (units: seconds), controlling response speed.
    \item $K$ is the \textbf{DC gain}, the steady-state ratio of output to input.
    \item $x(t)$ is the input, $y(t)$ is the output.
\end{itemize}

\noindent
\textbf{Key insight:} At time $t = \tau$, a rising exponential reaches $63.2\%$ of steady state, and a decaying exponential falls to $36.8\%$ of its initial value. The larger $\tau$, the slower the system responds.

\subsection{Step Response of First-Order Systems}

For a unit step input $x(t) = V_s u(t)$, the analytical solution is:
\begin{equation}
y(t) = K V_s \left(1 - e^{-t/\tau}\right) u(t).
\label{eq:step_response}
\end{equation}
This equation tells us:
\begin{itemize}
    \item At $t=0$: $y(0) = 0$ (continuity for capacitive circuits).
    \item At $t=\tau$: $y(\tau) \approx 0.632 \cdot K V_s$ (63.2\% of final value).
    \item As $t \to \infty$: $y(\infty) = K V_s$ (steady-state DC gain).
\end{itemize}

\subsection{Impulse Response of First-Order Systems}

If the input is an impulse $x(t) = K \delta(t)$, the impulse response is:
\begin{equation}
h(t) = \frac{K}{\tau} e^{-t/\tau} u(t).
\label{eq:impulse_response}
\end{equation}
Note that $h(t)$ starts at a peak value of $K/\tau$ and decays exponentially. The impulse response directly reveals the time constant through its decay rate.

\subsection{Measuring $\tau$ from Experimental Data}

When you measure noisy step-response data $y(t)$, you can extract $\tau$ by:

\begin{enumerate}
    \item \textbf{Remove baseline:} Subtract the initial value to isolate the transient.
    \item \textbf{For rising exponentials:} Transform the data as $\ln(V_\infty - y(t))$ and fit a line to the result. The slope $m$ satisfies $\tau = -1/m$.
    \item \textbf{For decaying exponentials:} Transform as $\ln(y(t))$ and fit a line. Again, $\tau = -1/m$.
    \item \textbf{Quantify error:} Compare your measured $\hat{\tau}$ with the theoretical value: $\text{Percent Error} = \left|\frac{\hat{\tau} - \tau_{\text{theory}}}{\tau_{\text{theory}}}\right| \times 100\%$.
\end{enumerate}

\noindent
This log-linearization technique is powerful because it converts an exponential curve fit into a linear regression problem, which MATLAB handles robustly.

\section{Hardware Circuits: RC and RL Low-Pass Configurations}
%--------------------------------------------------------------

\subsection{RC Low-Pass Circuit}

\textbf{Physical Layout:} The RC circuit is a simple first-order low-pass filter. The Arduino D7 pin (output) drives a resistor $R$. The voltage across the capacitor $C$ (to ground) is the output measured by A0.

\textbf{Circuit topology:}
\begin{itemize}
    \item D7 $\rightarrow$ Resistor $R$ $\rightarrow$ Node (measurement point) $\rightarrow$ Capacitor $C$ $\rightarrow$ GND.
    \item Arduino GND connected to the breadboard GND rail.
    \item A0 probe connected to the node between $R$ and $C$.
\end{itemize}

\textbf{Governing equation (derived from KVL):}
\begin{equation}
RC \frac{dV_C}{dt} + V_C = x(t), \qquad \text{where} \quad \tau_{RC} = RC.
\end{equation}

\noindent
For a step input $x(t) = V_s u(t)$, the response is:
\begin{equation}
V_C(t) = V_s \left(1 - e^{-t/\tau_{RC}}\right) u(t).
\end{equation}

\noindent
For an impulse approximation (narrow pulse), the peak response is:
\begin{equation}
V_C^{\text{peak}} \approx \frac{V_s T_p}{RC},
\end{equation}
where $V_s$ is the Arduino HIGH level (nominally 5 V) and $T_p$ is the pulse width in seconds.

\subsection{RL Low-Pass Circuit}

\textbf{Physical Layout:} The RL circuit contains a series resistor $R_{\text{ext}}$ and an inductor $L$ with its own winding resistance $R_L$. A \textbf{flyback diode} is essential to prevent voltage spikes when the inductor current is interrupted.

\textbf{Circuit topology:}
\begin{itemize}
    \item D7 $\rightarrow$ Resistor $R_{\text{ext}}$ $\rightarrow$ Node (measurement point) $\rightarrow$ Inductor $L$ (with winding resistance $R_L$) $\rightarrow$ GND.
    \item Flyback diode connected across the inductor: cathode (striped end) to the node between $R_{\text{ext}}$ and $L$, anode to the inductor's GND side.
    \item A0 probe connected to the node between $R_{\text{ext}}$ and $L$.
\end{itemize}

\textbf{Governing equations:}

The current $i(t)$ through the series $R_{\text{ext}}$ and $L$ satisfies:
\begin{equation}
L \frac{di}{dt} + (R_{\text{ext}} + R_L) i(t) = x(t),
\end{equation}
where $R_{\text{eff}} = R_{\text{ext}} + R_L$ is the effective resistance.

The voltage across $R_{\text{ext}}$ (the quantity of interest) is:
\begin{equation}
V_{R_{\text{ext}}}(t) = R_{\text{ext}} \cdot i(t).
\end{equation}

\noindent
However, \textbf{A0 measures the node voltage:}
\begin{equation}
V_{\text{node}}(t) = \text{voltage between } R_{\text{ext}} \text{ and } L.
\end{equation}

\noindent
\textbf{Critical correction:} To recover the voltage across the external resistor:
\begin{equation}
V_{R_{\text{ext}}}(t) = V_{\text{in}}(t) - V_{\text{node}}(t),
\end{equation}
where $V_{\text{in}}(t)$ is the Arduino D7 voltage (approximately 5 V when HIGH).

\noindent
The resulting first-order system has:
\begin{equation}
\tau_{RL} = \frac{L}{R_{\text{eff}}} = \frac{L}{R_{\text{ext}} + R_L}, \qquad K = \frac{R_{\text{ext}}}{R_{\text{eff}}}.
\end{equation}

\noindent
For a step input $x(t) = V_s u(t)$:
\begin{equation}
V_{R_{\text{ext}}}(t) = K V_s \left(1 - e^{-t/\tau_{RL}}\right) u(t).
\end{equation}

\subsection{Impulse Approximation in Hardware}

A finite pulse of width $T_p$ (microseconds) can approximate the Dirac delta $\delta(t)$ if $T_p \ll \tau$. As a rule of thumb:
\begin{itemize}
    \item If $T_p / \tau < 0.1$, the approximation is good.
    \item If $T_p / \tau \approx 0.5$, the pulse is too wide; the response will not look like a true impulse.
\end{itemize}

\noindent
The TA will assign a specific pulse width $T_p$ that is appropriate for your measured time constants.

\subsubsection*{Task 2: Extract Empirical Time Constant via Log-Linearization}

\textbf{Goal:} Fit an exponential to the measured data and extract $\hat{\tau}$.

\textbf{For step responses} (rising curves):

\begin{enumerate}
    \item \textbf{Find steady-state value:} Compute the average of the last 10\% of your data. Call this $V_\infty$.

    \item \textbf{Select a fitting window:} Choose a time range where transient dynamics dominate (e.g., 0 to $5\tau$). Avoid the very beginning (where $dV/dt$ is largest and noise dominates) and the very end (where noise matters more).

    \item \textbf{Transform the data:}
    \begin{equation}
    y_{\text{transform}} = V_\infty - V_{\text{measured}}.
    \end{equation}
    This converts a rising curve into a decaying curve.

    \item \textbf{Apply natural logarithm:}
    \begin{equation}
    y_{\text{log}} = \ln(y_{\text{transform}}).
    \end{equation}

    \item \textbf{Linear regression:} Use MATLAB's \texttt{polyfit(time, y\_log, 1)} to fit a line $y_{\text{log}} = m \cdot t + b$. The slope $m$ satisfies:
    \begin{equation}
    m = -\frac{1}{\tau}, \quad \text{so} \quad \hat{\tau} = -\frac{1}{m}.
    \end{equation}

    \item \textbf{Plot diagnostic figure:}
    \begin{itemize}
        \item \textbf{Top subplot:} Original measured signal + overlaid fitted exponential $A e^{-t/\hat{\tau}}$.
        \item \textbf{Bottom subplot:} Log-domain data ($\ln(V_\infty - V)$ vs $t$) with the fitted line overlaid.
    \end{itemize}
\end{enumerate}

\noindent
\textbf{For impulse responses} (decaying curves):

\begin{enumerate}
    \item \textbf{Remove baseline:} If the signal doesn't decay to zero (e.g., noise offset), subtract the final value.

    \item \textbf{Select fitting window:} Typically from the peak to $\approx 5\tau$ after the peak.

    \item \textbf{Apply log directly:}
    \begin{equation}
    y_{\text{log}} = \ln(y_{\text{measured}} - y_{\text{baseline}}).
    \end{equation}

    \item \textbf{Linear regression:} Fit a line and extract $\hat{\tau} = -1/m$ as before.
\end{enumerate}

\subsection*{A.1 RC Low-Pass Circuit Derivation}

\textbf{Setup:} A resistor $R$ in series with a capacitor $C$ to ground, with input $x(t)$ applied across the series combination. Output is the voltage $V_C(t)$ across the capacitor.

\textbf{Kirchhoff's Voltage Law (KVL):}
\begin{equation}
x(t) = V_R(t) + V_C(t),
\end{equation}
where $V_R(t) = R \cdot i(t)$ is the resistor voltage and $i(t) = C \frac{dV_C}{dt}$ is the capacitor current.

\noindent
\textbf{Substitution:}
\begin{equation}
x(t) = R \cdot C \frac{dV_C}{dt} + V_C(t).
\end{equation}

\noindent
\textbf{Standard form:}
\begin{equation}
RC \frac{dV_C}{dt} + V_C(t) = x(t), \quad \text{where} \quad \tau_{RC} = RC.
\end{equation}

\noindent
\textbf{Step Response} ($x(t) = V_s u(t)$, a constant voltage $V_s$ applied at $t=0$):

Solving the first-order ODE with initial condition $V_C(0) = 0$:
\begin{equation}
V_C(t) = V_s \left(1 - e^{-t/\tau_{RC}}\right) u(t).
\end{equation}
At $t = \tau_{RC}$, the capacitor has charged to $V_s(1 - e^{-1}) \approx 0.632 V_s$ (63.2\% of the final value).

\noindent
\textbf{Impulse Response} (input is $\delta(t)$, the Dirac impulse):

For an idealized impulse, the impulse response is:
\begin{equation}
h_{RC}(t) = \frac{1}{\tau_{RC}} e^{-t/\tau_{RC}} u(t) = \frac{1}{RC} e^{-t/(RC)} u(t).
\end{equation}
Note that $h(0) = 1/\tau_{RC}$ is the initial peak, and the signal decays with time constant $\tau_{RC}$.

\subsection*{A.2 RL Low-Pass Circuit Derivation}

\textbf{Setup:} A resistor $R_{\text{ext}}$ in series with an inductor $L$ (which has winding resistance $R_L$). Input $x(t)$ is applied across the series combination. Output is the voltage $V_{R_{\text{ext}}}(t)$ across the external resistor.

\textbf{Kirchhoff's Voltage Law (KVL):}
\begin{equation}
x(t) = V_{R_{\text{ext}}}(t) + V_L(t),
\end{equation}
where:
\begin{itemize}
    \item $V_{R_{\text{ext}}}(t) = R_{\text{ext}} \cdot i(t)$ (voltage across the external resistor).
    \item $V_L(t) = L \frac{di}{dt} + R_L \cdot i(t)$ (voltage across the inductor, including its winding resistance).
\end{itemize}

\noindent
\textbf{Combined:}
\begin{equation}
x(t) = R_{\text{ext}} \cdot i(t) + L \frac{di}{dt} + R_L \cdot i(t) = (R_{\text{ext}} + R_L) i(t) + L \frac{di}{dt}.
\end{equation}

\noindent
\textbf{Define effective resistance:}
\begin{equation}
R_{\text{eff}} = R_{\text{ext}} + R_L.
\end{equation}

\noindent
\textbf{Rearrange:}
\begin{equation}
L \frac{di}{dt} + R_{\text{eff}} i(t) = x(t).
\end{equation}

\noindent
\textbf{Express in terms of output $V_{R_{\text{ext}}} = R_{\text{ext}} \cdot i$:}

Taking the derivative: $i = V_{R_{\text{ext}}} / R_{\text{ext}}$ and $\frac{di}{dt} = \frac{1}{R_{\text{ext}}} \frac{dV_{R_{\text{ext}}}}{dt}$.

\noindent
Substituting:
\begin{equation}
L \frac{1}{R_{\text{ext}}} \frac{dV_{R_{\text{ext}}}}{dt} + R_{\text{eff}} \frac{V_{R_{\text{ext}}}}{R_{\text{ext}}} = x(t).
\end{equation}

\noindent
Multiply through by $R_{\text{ext}}$:
\begin{equation}
L \frac{dV_{R_{\text{ext}}}}{dt} + R_{\text{eff}} V_{R_{\text{ext}}} = R_{\text{ext}} x(t).
\end{equation}

\noindent
\textbf{Divide by $R_{\text{eff}}$ to get standard form:}
\begin{equation}
\frac{L}{R_{\text{eff}}} \frac{dV_{R_{\text{ext}}}}{dt} + V_{R_{\text{ext}}} = \frac{R_{\text{ext}}}{R_{\text{eff}}} x(t).
\end{equation}

\noindent
\textbf{Standard form:}
\begin{equation}
\tau_{RL} \frac{dV_{R_{\text{ext}}}}{dt} + V_{R_{\text{ext}}} = K \cdot x(t), \quad \text{where} \quad \tau_{RL} = \frac{L}{R_{\text{eff}}}, \quad K = \frac{R_{\text{ext}}}{R_{\text{eff}}}.
\end{equation}

\noindent
\textbf{Note:} The DC gain $K < 1$ because some of the input voltage is dropped across the inductor's winding resistance $R_L$.

\noindent
\textbf{Step Response} ($x(t) = V_s u(t)$):
\begin{equation}
V_{R_{\text{ext}}}(t) = K V_s \left(1 - e^{-t/\tau_{RL}}\right) u(t) = \frac{R_{\text{ext}}}{R_{\text{ext}} + R_L} V_s \left(1 - e^{-t/\tau_{RL}}\right) u(t).
\end{equation}

\noindent
\textbf{Impulse Response:}
\begin{equation}
h_{RL}(t) = \frac{K}{\tau_{RL}} e^{-t/\tau_{RL}} u(t) = \frac{R_{\text{ext}}}{L} e^{-t/\tau_{RL}} u(t).
\end{equation}

\subsection*{A.3 Log-Linearization for Time-Constant Extraction}

\textbf{Goal:} Extract the time constant $\tau$ from experimental step or impulse response data.

\noindent
\textbf{For step/rising response} $y(t) = Y_\infty (1 - e^{-t/\tau})$:

Transform: Let $z(t) = Y_\infty - y(t) = Y_\infty e^{-t/\tau}$.

\noindent
Take natural log:
\begin{equation}
\ln(z) = \ln(Y_\infty) - \frac{t}{\tau}.
\end{equation}

\noindent
This is a line with slope $m = -1/\tau$. Fit with \texttt{polyfit(time, log(z), 1)} and extract $\hat{\tau} = -1/m$.

\noindent
\textbf{For impulse/decaying response} $y(t) = A e^{-t/\tau}$:

Take natural log directly:
\begin{equation}
\ln(y) = \ln(A) - \frac{t}{\tau}.
\end{equation}

\noindent
Again, fit a line and extract $\hat{\tau} = -1/m$.

\textbf{How to set these parameters:}

\begin{itemize}
    \item \texttt{SAMPLE\_RATE\_HZ}: Choose a rate such that $f_s \ge 10 / \tau_{\min}$. This ensures you capture at least 10 samples per time constant (Nyquist-like criterion). For $\tau_{\min} = 1$ ms, use $f_s \ge 10$ kHz. For $\tau_{\min} = 10$ ms, use $f_s \ge 1$ kHz.

    \item \texttt{N\_SAMPLES}: Set so that the total acquisition time is at least $5\tau_{\max}$ (where $\tau_{\max}$ is your larger time constant). Acquisition time = $N_{\text{samples}} / f_s$. For example: $N_{\text{samples}} = 5000$ samples at $f_s = 5000$ Hz gives an acquisition of 1 second, which captures $\approx 100$ time constants if $\tau = 10$ ms.

    \item \texttt{PULSE\_WIDTH\_US}: TA will specify. Typical range: 50--500 $\mu$s.

    \item \texttt{INPUT\_TYPE}: Change to \texttt{IMPULSE} to test impulse response. Leave as \texttt{STEP} for step response.
\end{itemize}

\subsection*{B.2 Serial Protocol}

The Arduino operates as follows:

\begin{enumerate}
    \item \textbf{Waits for trigger:} After upload, the Arduino waits for a character on the serial port.

    \item \textbf{User sends 's':} In the Arduino Serial Monitor, type \texttt{s} and press Enter. The Arduino will:
    \begin{itemize}
        \item Flash the LED on D13.
        \item Apply the configured signal (step or narrow pulse) on D7.
        \item Acquire \texttt{N\_SAMPLES} readings from A0 at the specified sample rate.
        \item Stream data to the serial port.
    \end{itemize}

    \item \textbf{Data format:} Each line contains \texttt{timestamp\_us,adc\_count}, e.g.:
    \begin{verbatim}
0,512
200,524
400,538
600,556
...
    \end{verbatim}
    where \texttt{timestamp\_us} is in microseconds (elapsed time since start of acquisition) and \texttt{adc\_count} is the raw 10-bit ADC reading (0--1023).

    \item \textbf{Conversion to voltage:} In MATLAB, convert ADC counts to volts using the Arduino reference voltage (nominally 5.0 V):
    \begin{equation}
    V = (\text{ADC count}) / 1023 \times 5.0 \text{ V}.
    \end{equation}
\end{enumerate}

\subsection*{C.1 Data Import and Conversion}

The provided \texttt{Lab05\_Serial\_Reader.m} skeleton handles serial communication. Once you have raw data (\texttt{timestamp\_us} and \texttt{adc\_count}), convert to engineering units:

\begin{verbatim}
% Raw data from Arduino
timestamp_us = data(:, 1);              % in microseconds
adc_count = data(:, 2);                 % 10-bit ADC (0-1023)

% Convert to seconds and volts
time_s = timestamp_us / 1e6;            % convert to seconds
V_in_ref = 5.0;                         % Arduino 5V reference
voltage_V = (adc_count / 1023) * V_in_ref;  % ADC to volts (0-5V)

% Remove initial offset (optional, improves log-fit)
V_offset = mean(voltage_V(1:10));       % average of first 10 samples
voltage_V = voltage_V - V_offset;
\end{verbatim}

\subsection*{C.2 Theoretical Curve Generation}

For step response:
\begin{verbatim}
% RC step response: V_C(t) = V_s * (1 - exp(-t/tau))
tau_theory = tau_RC;           % or tau_RL
V_s = 5.0;                     % step amplitude
V_theory = V_s * (1 - exp(-time_s / tau_theory));

% RL step response includes DC gain K
K_RL = R_ext / (R_ext + R_L);
V_theory = K_RL * V_s * (1 - exp(-time_s / tau_theory));
\end{verbatim}

\noindent
For impulse response:
\begin{verbatim}
% RC impulse: h(t) = (1/tau) * exp(-t/tau)
h_theory = (1 / tau_theory) * exp(-time_s / tau_theory);

% RL impulse includes DC gain
h_theory = (K_RL / tau_theory) * exp(-time_s / tau_theory);
\end{verbatim}

\subsection*{C.3 RL Node-to-Resistor Voltage Conversion}

\textbf{Critical step for RL analysis:}

The Arduino A0 measures the voltage at the node between $R_{\text{ext}}$ and $L$. To recover the voltage \textbf{across $R_{\text{ext}}$}, use KVL:

\begin{verbatim}
% A0 measures node voltage V_node
V_in = 5.0;                              % Arduino HIGH level during step
V_Rext = V_in - V_node;                  % voltage across R_ext

% For RL step response, use V_Rext for curve fitting, not V_node
% V_Rext(t) = K*V_s * (1 - exp(-t/tau_RL))

% For RL impulse response:
% h(t) = K/tau * exp(-t/tau)
\end{verbatim}

\subsection*{C.4 Log-Linearization for Time-Constant Extraction}

For a rising step response:

\begin{verbatim}
% Step response: y(t) = V_s(1 - exp(-t/tau))
% Transform: z(t) = V_s - y(t) = V_s * exp(-t/tau)
% Log: ln(z) = ln(V_s) - t/tau
% Fit: ln(z) = m*t + b, where m = -1/tau

% Compute steady state
V_ss = mean(voltage_V(end-100:end));     % average of last 100 samples

% Transform (rising to decay)
z = V_ss - voltage_V;
z = z(z > 0.01);                        % keep only positive values (noise mitigation)
time_fit = time_s(1:length(z));         % corresponding times

% Log transform
z_log = log(z);

% Linear regression
coeffs = polyfit(time_fit, z_log, 1);   % fit line: z_log = m*t + b
m = coeffs(1);                           % slope
tau_measured = -1 / m;                  % extract tau

% For validation, compute fitted curve
z_fitted = exp(coeffs(1)*time_fit + coeffs(2));
V_fitted = V_ss - z_fitted;
\end{verbatim}

\noindent
For a decaying impulse response:

\begin{verbatim}
% Impulse response: y(t) = A * exp(-t/tau)
% Log: ln(y) = ln(A) - t/tau
% Fit: ln(y) = m*t + b, where m = -1/tau

% Remove baseline offset
y_offset = mean(voltage_V(end-100:end));
y_centered = voltage_V - y_offset;
y_centered = y_centered(y_centered > 0.01);  % keep positive values
time_fit = time_s(1:length(y_centered));

% Log transform
y_log = log(y_centered);

% Linear regression
coeffs = polyfit(time_fit, y_log, 1);
m = coeffs(1);
tau_measured = -1 / m;

% Fitted curve
y_fitted = exp(coeffs(1)*time_fit + coeffs(2));
\end{verbatim}

\subsection*{C.5 Percent Error Calculation}

\begin{verbatim}
% Given theoretical tau and measured tau
tau_theory = 1e-3;         % example: 1 ms
tau_measured = 1.05e-3;    % example: 1.05 ms

% Compute error
error_absolute = abs(tau_measured - tau_theory);
error_percent = (error_absolute / tau_theory) * 100;

fprintf('Theoretical tau: %.3f ms\n', tau_theory*1e3);
fprintf('Measured tau:    %.3f ms\n', tau_measured*1e3);
fprintf('Absolute error:  %.3f ms\n', error_absolute*1e3);
fprintf('Percent error:   %.1f %%\n', error_percent);
\end{verbatim}

\subsection*{Hardware Issues}

\begin{enumerate}
    \item \textbf{Arduino does not respond to Serial Monitor input.}
    \begin{itemize}
        \item Verify USB cable is connected and the Arduino IDE shows the correct COM port.
        \item Recompile and re-upload the sketch.
        \item Check that the baud rate in Serial Monitor is set to 115200.
    \end{itemize}

    \item \textbf{Voltage trace is flat at 0 V or does not change.}
    \begin{itemize}
        \item Check that A0 is connected to the measurement node (between R and C for RC circuit, or between $R_{\text{ext}}$ and $L$ for RL circuit).
        \item Use a multimeter to verify that the node voltage changes when D7 is toggled manually.
        \item Verify that the Arduino GND is connected to the breadboard GND rail.
        \item If the trace is constant but non-zero, the circuit may be stuck in a steady state; check component values.
    \end{itemize}

    \item \textbf{RL circuit: Arduino resets when applying step, or USB disconnects.}
    \begin{itemize}
        \item The flyback diode is missing or incorrectly oriented. Verify diode cathode (striped end) points to the measurement node, and anode points to GND.
        \item Without the diode, the inductor's back-EMF can exceed 5 V and damage the Arduino. Stop immediately and fix the diode.
        \item Use a multimeter in diode mode to confirm the diode conducts backward (from GND to node).
    \end{itemize}

    \item \textbf{Voltage spikes or ringing on the scope.}
    \begin{itemize}
        \item Breadboard layout: keep wires short and avoid loops.
        \item Verify component tolerances; high capacitive or inductive parasitics can cause ringing.
        \item This is \textbf{non-ideal}, but expected in a breadboard setup. Document it in your discussion.
    \end{itemize}
\end{enumerate}

\subsection*{Arduino Acquisition Issues}

\begin{enumerate}
    \item \textbf{Serial Monitor shows no data after sending 's'.}
    \begin{itemize}
        \item Verify the LED on D13 flashes. If it does not, the Arduino may not be receiving the trigger character. Check Serial Monitor connection and baud rate.
        \item Check that \texttt{INPUT\_TYPE} is defined as either \texttt{STEP} or \texttt{IMPULSE}, not an invalid value.
        \item Verify \texttt{N\_SAMPLES} is not too large (max \texttt{\textasciitilde 30000} for Arduino Uno memory).
    \end{itemize}

    \item \textbf{Data arrives very slowly, or MATLAB hangs waiting for data.}
    \begin{itemize}
        \item The sample rate may be too high for the Arduino to keep up. Reduce \texttt{SAMPLE\_RATE\_HZ}.
        \item Check that serial transmission is at 115200 baud (not a slower rate).
        \item The Arduino may be overflowing its buffer. Verify \texttt{N\_SAMPLES} is reasonable ($<10000$ for safety).
    \end{itemize}

    \item \textbf{ADC readings jump erratically or show noise spikes.}
    \begin{itemize}
        \item This is normal for breadboard circuits. Noise from switching and parasitic capacitance is expected.
        \item Mitigation: use a smoothing median filter in MATLAB (e.g., \texttt{y\_smooth = medfilt1(y, 5)}) to remove outliers without introducing lag.
        \item Verify A0 is not near noisy digital lines (e.g., D7 during switching). Reroute if possible.
    \end{itemize}
\end{enumerate}

\subsection*{MATLAB Analysis Issues}

\begin{enumerate}
    \item \textbf{MATLAB hangs when calling the serial reader.}
    \begin{itemize}
        \item Verify the Arduino is ready and waiting for the 's' trigger.
        \item Check that MATLAB's serial port name matches the Arduino's COM port (e.g., 'COM3', not 'COM1').
        \item Ensure Arduino baud rate (115200) matches MATLAB's serial settings.
    \end{itemize}

    \item \textbf{Voltage conversion produces out-of-range values (e.g., $>5$ V or $<0$ V).}
    \begin{itemize}
        \item The ADC should output 0--1023. If you see values outside this range, there is a data corruption issue.
        \item Check the serial data in the Serial Monitor: confirm values are in the expected range.
        \item The Arduino reference voltage may not be 5.0 V. Measure the actual AREF voltage with a multimeter and update the conversion formula.
    \end{itemize}

    \item \textbf{Overlay plot shows measured data but no theoretical curve.}
    \begin{itemize}
        \item Verify you computed the theoretical curve using the correct \textbf{measured} time constants ($\tau_{RC}$, $\tau_{RL}$), not assumed values.
        \item For RL circuits, ensure you corrected the A0 voltage to get $V_{R_{\text{ext}}}$ (using $V_{R_{\text{ext}}} = 5.0 - V_{\text{node}}$).
        \item Check the time vector: if theory uses a different time base than measured data, the curves will not align.
    \end{itemize}

    \item \textbf{Log-linearization plot is curved, not straight.}
    \begin{itemize}
        \item \textbf{Common causes:}
        \begin{itemize}
            \item Baseline offset not removed (especially critical for step responses).
            \item Impulse pulse is too wide ($T_p$ not $\ll \tau$); the data exhibits more complex dynamics than a pure exponential.
            \item Strong noise on the measured signal. Median filter before log transform.
            \item For step responses, you may have selected a fitting window that includes the nonlinear transient region.
        \end{itemize}
        \item \textbf{Fix:}
        \begin{itemize}
            \item Carefully remove the baseline: $z = V_{\text{final}} - V_{\text{measured}}$ (for rising steps).
            \item Select the fitting window from $t \approx 0.2\tau$ to $t \approx 4\tau$ (avoid the very beginning and end).
            \item Apply a median filter to reduce noise spikes before log transform.
        \end{itemize}
    \end{itemize}

    \item \textbf{Percent error is $>30\%$ for both circuits.}
    \begin{itemize}
        \item Verify your component measurements with the multimeter. Resistor and capacitor tolerances can be large ($\pm 10\%$ or more).
        \item Check that you used the \textbf{correct} measured values in your theoretical $\tau$ calculation (not nominal values from the component labels).
        \item For RL circuits, did you include the inductor's winding resistance $R_L$ in $R_{\text{eff}}$? This is critical.
        \item Examine the raw Arduino data for signs of noise or ADC quantization. Smooth if needed.
        \item If RC error is high, check capacitor leakage or parasitic resistance. If RL error is high, re-verify the flyback diode and RL measurement.
    \end{itemize}

    \item \textbf{RC and RL percent errors are very different (one $<10\%$, the other $>30\%$).}
    \begin{itemize}
        \item For RL circuits, the key suspect is the inductor winding resistance $R_L$. If $R_L$ is measured incorrectly, $\tau_{RL}$ will be wrong.
        \item Re-measure $R_L$ by removing the inductor from the breadboard and measuring it directly with the multimeter.
        \item For RC circuits, capacitor tolerance can be large. Verify with the multimeter capacitance mode.
        \item Make sure your curve-fit window is appropriate for both circuits; they may have different optimal windows.
    \end{itemize}
\end{enumerate}
