\section{Abstract}
This semester, you will interface high-level software (MATLAB) with physical embedded hardware (Arduino Mega). To ensure a smooth "sampling pipeline" in future labs, your environment must be configured correctly. This lab guides you through the installation of MATLAB R2023b+, Arduino IDE 2.x, and the necessary hardware drivers to communicate with your Mega 2560.

\section{Objectives}
In this assignment, you will:
\begin{enumerate}
    \item Locate the ECE 280 laboratory in Teer 116.
    \item Verify MATLAB version compatibility and install required toolboxes.
    \item Configure Arduino IDE 2.x with the correct Board Support Packages and Libraries.
    \item Solve USB-to-Serial driver issues (the \#1 cause of lab connectivity failures).
\end{enumerate}

\subsection{MATLAB Installation \& Toolboxes}
\textbf{Required MATLAB version:} \textbf{R2020a minimum} (\textbf{R2023b+ strongly recommended}).

\textbf{Why this version floor matters:}
\begin{itemize}
    \item \texttt{exportgraphics()} was introduced in R2020a. Older versions fail figure-export deliverables.
    \item \texttt{serialport()}, \texttt{configureTerminator()}, and \texttt{readline()} were introduced in R2019b.
    \item Legacy \texttt{serial()} API is deprecated and not supported in our starter scripts.
\end{itemize}

\centering

\begin{tabularx}{\linewidth}{l l X}
\toprule
\textbf{Toolbox} & \textbf{Status} & \textbf{Why Needed / Typical Functions} \\ \midrule
Instrument Control Toolbox & \textbf{Required} & Serial communication with Arduino: \texttt{serialport}, \texttt{configureTerminator}, \texttt{readline}, \texttt{flush}. \\
Signal Processing Toolbox & \textbf{Required} & Filter/frequency analysis and report questions: \texttt{freqz}, \texttt{fir1}, \texttt{db2mag}. \\

\subsection{USB Drivers \& Port Permissions}
Driver issues are the most common cause of failed serial communication.

\begin{table}[h]
\centering
\caption{USB Driver by Board Variant}
\begin{tabularx}{\linewidth}{l l X}
\toprule
\textbf{Board Variant} & \textbf{USB Chip} & \textbf{Driver Requirement} \\ \midrule
Official Arduino Mega 2560 & ATmega16U2 & Native CDC-ACM support on modern Windows/macOS/Linux (usually no manual install). \\
Most clone/off-brand Mega boards & CH340G & Manual CH340 driver install required. \\
Some clone boards & FTDI FT232 & Usually auto-installed; FTDI vendor driver may improve stability. \\
\bottomrule
\end{tabularx}
\end{table}

\begin{table}[h]
\centering
\caption{CH340 Driver Installation Notes}
\begin{tabularx}{\linewidth}{l l X}
\toprule
\textbf{OS} & \textbf{Source} & \textbf{Notes} \\ \midrule
Windows 10/11 & \url{https://www.wch-ic.com} & Run installer as Administrator and reboot. \\
macOS Ventura/Sonoma+ & \url{https://www.wch-ic.com} & Approve kernel/security prompt in System Settings $\rightarrow$ Privacy \& Security. \\
Linux (kernel 3.12+) & Built-in & Run \texttt{sudo usermod -aG dialout \$USER}, then log out/in. \\
\bottomrule
\end{tabularx}
\end{table}

\subsection{Finding the Correct Serial Port}
\begin{table}[h]
\centering
\caption{Port Discovery by Operating System}
\begin{tabularx}{\linewidth}{l X X}
\toprule
\textbf{OS} & \textbf{Where to Check} & \textbf{Typical Port Name} \\ \midrule
Windows & Device Manager $\rightarrow$ Ports (COM \& LPT) & COM3, COM4, ... \\
macOS & Terminal: \texttt{ls /dev/tty.*} & \texttt{/dev/tty.usbmodem*}, \texttt{/dev/tty.wchusbserial*} \\
Linux & Terminal: \texttt{ls /dev/ttyUSB* /dev/ttyACM*} & \texttt{/dev/ttyUSB0}, \texttt{/dev/ttyACM0} \\
\bottomrule
\end{tabularx}
\end{table}

\subsection{Installation Checklist}
Complete the following checklist before attending Lab 1.
\begin{itemize}
    \item[$\square$] MATLAB R2020a or later installed (R2023b+ recommended).
    \item[$\square$] Instrument Control Toolbox installed and licensed.
    \item[$\square$] Signal Processing Toolbox installed and licensed.
    \item[$\square$] DSP System Toolbox installed and licensed.
    \item[$\square$] Control System Toolbox installed and licensed.
    \item[$\square$] Audio Toolbox installed and licensed.
    \item[$\square$] Simulink installed and licensed.
    \item[$\square$] Arduino IDE 2.x installed.
    \item[$\square$] Arduino AVR Boards package installed via Boards Manager.
    \item[$\square$] TimerOne library installed via Library Manager.
    \item[$\square$] Correct USB driver installed for your board (CH340 if clone).
    \item[$\square$] Port permissions configured (Linux dialout / macOS approval if needed).
    \item[$\square$] Port name identified and verified in MATLAB script settings.
    \item[$\square$] Arduino Serial Monitor tested at 115200 baud.
    \item[$\square$] Arduino IDE Serial Monitor \textbf{closed} before running MATLAB (single-app COM port access).
\end{itemize}
